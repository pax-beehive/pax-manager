# Browser operator API handoff

## Change and flow

Adds owner-authorized `POST /api/v1/user/:user_id/nodes/:node_id/daemon/browser`.
The handwritten handler decodes operation/payload, the userapi service checks
operation and payload bounds, and `queryNodeDaemon` resolves the authenticated
principal and verifies node ownership before issuing `browser.control`.
The payload is a transient node-control query, not a stored daemon command or
ACP message. Native credentials and Docker VNC authentication remain on paxd.

Allowed operations are state, policy, decide, revoke, secret, resume_sensitive,
view, vnc_open, vnc_exchange, and vnc_close. Pairing, login-code creation,
credential consumption and arbitrary proxy routes are deliberately unavailable.
The bridge uses the existing in-process NodeControlHub. Multi-instance traffic
must route to the instance holding the node connection; no new distributed media
routing is provided. A viewer can add load/latency to the sequential node tunnel.

## Generation and rollout

IDL source: api/pax_manager.thrift. Run `make generate` with Go 1.26 to update
Hertz models/router/handlers, OpenAPI and mocks. The current generator also
normalizes pre-existing model output and generates previously missing secret
channel delegates; no generated file was edited by hand.

Deploy alongside the matching paxd, pax-console and agent-browser-runtime
changes. Their full rollout guide is agent-browser-runtime/docs/pax-browser-mvp.md.
Use the existing deployment workflow; no production service was deployed by
these source changes.

## Verification

- `GOCACHE=/tmp/pax-manager-go-cache go test -count=1 ./...`: passed.
- `GOCACHE=/tmp/pax-manager-go-cache go build -o /tmp/pax-manager-browser ./cmd/manager`: passed.
- New tests check node ownership before forwarding, transient query use, and
  rejection of credential/proxy operations.
- `make fmt-check` fails on pre-existing golines differences in unrelated files.
  Unrelated whole-repository formatter edits were removed from this change.
- `make lint` reports existing errcheck in storage/e2ee_keys.go plus existing
  gocyclo findings in transport, storage and daemon lifecycle methods. None is
  in the new browser handler or service method.

This API relays browser media over authenticated transport; it does not make
media end-to-end encrypted against Manager. The password sender independently
uses the existing sealed secret-channel payload; passwords are never browser
operator request arguments.
