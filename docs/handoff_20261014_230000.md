# Native project creation

Android Home now offers Sessions / Projects switching and a New project form.
The gateway adds only POST user/self/projects to allowedNativeUserRoute, shared
by the native WorkOS and user-key paths. The Manager already implements this
endpoint: CreateProjectRequest accepts display_name and optional
parent_project_id, and returns data.project. Android currently creates root
projects with display_name only. IDs are server-assigned; ambiguous submissions
must be checked in the project list rather than automatically retried.

Identity verification, regional assignment, signed Manager identity, resource
ownership and Access configuration remain unchanged. No Go/generated artifacts,
secrets, bindings, or remote variables change. No regeneration is needed. This
adds a mobile capability and does not resolve a legacy protocol issue.
