# Manager and home_dev resource metrics

Manager exposes `pax_websocket_connections{kind}` on the existing metrics
listener. Successful upgrades increment on the authenticated connection
handlers and defer a decrement until each handler exits. Kinds are
`control` for paxd control, `agent` for legacy Agent and ACP upstream, and
`client` for user ACP and voice WebSockets. The gauge stays accurate if an
operator toggles the metrics feature while established connections still exist.
The dashboard shows the three kinds and their total.

The same dashboard reads Manager process CPU, resident memory, Go heap and
goroutine metrics from the registered process and Go collectors. Prometheus
can optionally scrape Node Exporter on home_dev as `pax-home-dev`. The exporter
shares the existing HTTPS CA and requires authentication. The additional scrape
job is empty by default. Nothing is collected from the home_server host.

The change adds no database schema or generated artifacts. To verify, check
both Prometheus targets, compare the home_dev filesystem and CPU samples with
host commands, and exercise a connect/disconnect with the metrics gate enabled.
See [Pax observability](../deploy/observability/README.md) for deployment and
the optional host target.
