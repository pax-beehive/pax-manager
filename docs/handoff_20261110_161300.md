# Secretary retained evidence substring correction

## Problem and behavior

The previous retained-evidence resolver required a generated quotation to equal
the entire old baseline quote. This differed from the literal containment rule
used for changed messages and verified tool reads. An agent could copy a shorter
contiguous excerpt of evidence already supplied in the same unchanged summary,
yet the whole batch failed with a generic quote-not-visible error.

An owner-scoped read-only PostgreSQL comparison examined eight quote-invalid
attempts across four source sessions. Six attempts contain this false rejection;
five have no other unmatched quote in that comparison. The other three attempts
also or instead contain changed quotations that should remain rejected. All
eight have no additional original-message reads. No production source text,
model output, quote or receipt was exported for this diagnosis. The comparison
does not establish that every output passes all other publication checks.

The resolver now accepts a nonempty contiguous literal substring of a quote in
the same unchanged baseline. It returns that shorter quote with the old exact
message-version reference and view, leaving the old revision untouched. Reset,
changed and removed messages still require verification. Existing coverage,
version, view and receipt checks remain authoritative. Paraphrases, joined
excerpts and another node's evidence remain invalid.

## Boundaries

The shared helper applies to both the current node publication path and the
legacy rolling summary path. The node prompt explicitly describes valid shorter
excerpts. There is no schema, generated API, storage encoding or ES change in
this correction. It is appended to Manager PR 227; the Console PR is unchanged.

No production task was reset or replayed. An old blocked batch needs the normal
owner-authorized retry after deployment. Actual source changes or invalid
quotations are still errors; accepting a substring must not become fuzzy quote
matching or automatic source guessing.
