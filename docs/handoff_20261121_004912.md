# Durable managed sandbox model permissions

An authenticated owner enables free model access with the existing
`POST /api/v1/starter/wake` target. A sandbox Agent's opt-in and provisioning
state are stored separately. The verified Agent uses the existing account's
monthly wallet and platform model pool.

The host still provisions each sandbox boot through authenticated jobs. Manager
revalidates the owner, sandbox Node, Agent, harness, and exact current sandbox
lease before it assigns a job. The signing lineage stays fixed across later
boots. The scoped model key is given to the worker in the existing job field.
Only a catalog lookup is allowed before the first successful provisioning.
Afterward, model admission uses current ownership, feature gate, opt-in, budget,
and model policy independently of the sandbox lease. Active atomic admissions
can settle as before.

`POST /api/v1/starter/revoke` accepts the exact owned Node and Agent. It revokes
the key even while the sandbox is off, without affecting other Agents or the
wallet. Explicit re-enabling creates a different key. `GET /api/v1/starter`
reports `sandbox_model_access.agents[].enabled` without credentials. A Codex
worker may report its current guest catalog IDs on ready. Manager projects those
IDs in order for this ready grant after filtering current enabled policy.

Existing lease-bound sandbox grants can continue running with their current
key. Manager migrates a prior opt-in when the same verified Node and Agent are
next provisioned. This path needs no owner intervention or SQL migration.
Current keys fail closed on Manager versions without durable-key support.
Avoid a mixed-version write rollout across services sharing hosting state.

Regenerate HTTP bindings and OpenAPI with `make generate`. Release Manager and
the region-directory allowlist before publishing UI actions that depend on the
new revoke endpoint. Running the checks locally requires Go 1.26 selected via
gvm and the region-directory npm dependencies:

```sh
GOWORK=off make fmt-check lint
GOWORK=off GOCACHE=/tmp/pax-manager-go-cache go test -count=1 ./...
GOWORK=off GOCACHE=/tmp/pax-manager-go-cache go build -o /tmp/pax-manager-build-check ./cmd/manager
cd workers/region-directory
npm run typecheck
npm test
```
