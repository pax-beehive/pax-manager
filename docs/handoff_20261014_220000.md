# Native mobile session creation routes

The Android New session form needs three existing Manager endpoints through the
native gateway. This change adds only these exact user/self patterns:

- GET nodes/:node_id/agents
- GET projects/:project_id/targets
- POST nodes/:node_id/agents/:agent_id/sessions

Verified WorkOS identity, regional assignment, signed Manager identity, and
resource authorization remain unchanged. No secrets, Access policy, bindings,
database, Go source, or generated artifacts change. Regeneration is unnecessary.
The Android client passes an explicit manager session ID, project, workspace
roots and pax_config.cwd. Unknown mutation outcomes are recovered by GET of the
same session instead of repeating the POST.
