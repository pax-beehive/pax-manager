# Native client gateway

## Problem and scope

Android instrumentation on 2026-10-13 received HTTP 302 Cloudflare Access login
redirects from both regional origins before Manager device login could run.
A host-side Python probe separately received 403/error 1010; it did not describe
the Android failure. Browser cookies and shared service credentials must not be
copied to the phone.

## Change

`workers/region-directory/src/native.ts` handles only
`/api/v1/native/{us|hk}/...` on the canonical public origin. It translates the
suffix to the existing `/api/v1/...` Manager contract. Anonymous access is limited
to POST device-login start/poll. Start requires `client_commit_v1`. Start and poll
use independent per-IP rate-limit bindings and bounded JSON bodies.
Other allowlisted requests require a user API key; Manager validates the owner,
revocation and resource permissions. Region selection is only a routing hint.
No mutation retries or alternate-region writes occur.

Origin Access service credentials stay in Worker secrets. Forwarding strips
browser cookies, user hints, identity assertions and incoming Access credentials.
The Worker does not manufacture a user identity. It preserves Last-Event-ID,
Idempotency-Key and streaming responses, rejecting origin redirects and HTML.
No Go/generated code, schema, WorkOS flow, browser route or Access policy changes
are needed.

## Activation and rollback

The handler defaults to disabled unless `NATIVE_API_ENABLED=true`. Following
explicit user approval, the browser production config enables it. It adds one route and
two rate-limit bindings: 20 starts/minute and 120 polls/minute per IP per Cloudflare
location. Account inventory of 11 Workers confirmed namespace IDs 2026101301 and
2026101302 were unused before activation. These limits are not exact global quotas.

After explicit production approval, verify the active Worker revision and preserve
any newer production changes. Deploy the browser config with `--keep-vars` and
explicitly set `NATIVE_API_ENABLED=true`. Retain the previous deployment ID.
Disable the flag or restore that deployment to roll back. Do not disable Access
on regional origins. Existing Worker service credentials must be present.
