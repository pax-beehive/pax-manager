# Regional device setup script

Add authenticated GET /api/v1/user/:user_id/device-setup. Existing account routing
selects the regional Manager. Metadata comes exclusively from deployment origins:
PAX_SETUP_DOWNLOAD_URL for artifacts and PAX_SETUP_MACHINE_URL for registration.
Missing or invalid configuration fails closed with 503. Request Host is not used.

The public installer endpoint accepts ?setup=1 to serve a token-free bootstrap;
no-query requests retain the existing installer behavior. The bootstrap fully
downloads and validates the installer before execution, sets regional endpoints,
propagates failures and removes temporary files. Tokens remain process environment
values, never script URLs. The Console no longer maintains a regional domain map.

Deploy both configured regional Managers before the Console. Existing production
deploy agents preserve container environments, so these variables need explicit
provisioning before rollout. Release's environment-driven Docker adapter injects
them from urls.api and urls.wsapi. No database migration is needed. Verify the
public query endpoint is not intercepted by Access before releasing Console.

Validation includes Go route/config/script tests and a Console cross-repository
harness using this renderer, real curl/Bash and the real paxd installer. Harness
artifacts and registration endpoints are fixtures, not production enrollment.
The harness README documents reproduction and scope. Full repository checks are
recorded in the workspace installer report. No production deployment was performed.
