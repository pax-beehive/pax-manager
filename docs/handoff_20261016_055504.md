# Native daemon tools gateway rollout repair

## Cause and change

Android device tools showed HTTP 404 while displaying the last reported paxd
version. The merged gateway source contained the new routes, but the live Worker
still ran version 6a35eca0-b8a9-4d65-b59f-8259c3903394 (project creation rollout).
Unauthenticated node-detail and stable-release routes returned not_found before
verification, confirming the missing gateway routes.

Deployed workers/region-directory with wrangler.browser.jsonc and --keep-vars.
The source exactly matched origin/main at 459a49a for this directory. No source,
authentication policy, secret, or environment variable changes were introduced.
The route additions were previously approved by the user and merged in PR #181.

Current Worker version: 66f00825-0e97-4b3f-ada3-2b94b2a34172.

## Verification

- TypeScript typecheck, 172 Worker tests, and production-config dry run passed.
- Previously missing GET routes now return 401 without credentials.
- Disallowed POST to the stable-release lookup still returns 404.
- On the connected Pixel 11 Pro Fold, Settings > Devices > MacBook-Pro-4.local
  now displays Online, paxd 0.1.55, Latest stable: 0.1.56, and Upgrade paxd with
  no error. This verifies the authenticated node-detail and release lookup flow.
- No upgrade command was submitted. No Android rebuild was needed for this fix.

The fix only deploys the merged Worker. This verification does not establish a
completed daemon upgrade or live directory browsing. No issue status changed.
