# Image publication checkpoint

Adds a reusable/manual Publish image workflow called after successful main CI.
Application code, authentication, storage and runtime environment are unchanged.
The flow is exact commit -> GHCR -> digest pull verification -> Release catalog.
See image-release.md for secrets, retries and the agent registry limitation.
Validation covers workflow syntax and 16 isolated HTTP registration scenarios.
No production container was replaced. Live workflow validation is pending merge.
