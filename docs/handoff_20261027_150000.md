# Artifact upload source turn

## Change

Manager persists optional `source.turn_id` as immutable publication source
metadata. The companion paxd change captures the active turn in the local
control handler before file snapshotting and persists it with the upload job.
Retries and restarts retain that value. The source turn overrides missing tool
attribution and prevents a tool in another turn from projecting the publication.

The companion Console change preserves `source_session_seq` ordering through
history calibration, not just page flattening. Upload status updates reuse the
existing card. No upload-success text messages or historical repair are added.

## Deployment

Apply `db/init.sql` before starting the new Manager binary. The additive
`artifact_publications.turn_id` column defaults to an empty string for old rows.
Deploy Manager before paxd so new source metadata is retained. The node
registration endpoint remains compatible with older paxd clients.

Issue 045 remains resolved with this follow-up. Old duplicate card records and
Mermaid MIME classification remain outside this change.
