# Prometheus metrics feature gate

The Manager now controls HTTP metrics collection and scraping through its
database-backed `feature.metrics` gate. The default is Off. Only GA enables
the machine scrape. User-scoped rollout stages remain disabled for this gate.

The existing HTTPS endpoint uses port 9109 and fixed files under
`/run/pax-metrics`. The scraper peer, TLS certificates, and token stay in
read-only deployment mounts. The Manager can start if the metrics listener
cannot be provisioned. See the monitoring deployment README for the file
names and the gate settings.

The one-time port mapping and file mounts are part of the Manager deployment.
After those are in place, enable or disable the gate through the existing admin
workflow. No schema migrations or generated artifacts are required.
