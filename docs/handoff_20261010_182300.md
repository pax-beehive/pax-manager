Issue 034 remains partial. This change fixes the browser proxy allowlist for the
generic artifact download endpoint used by the paxl upgrade dialog. Routing
continues to use verified identity and the existing account assignment. Only
GET/HEAD are accepted; admin and machine endpoints remain excluded.

No Go service, generated transport, database, secret or binding changes. Deploy
the merged Worker with `npm run deploy -- --message COMMIT` from
`workers/region-directory`; the script selects wrangler.browser.jsonc and keeps
remote vars. Check existing bindings before deployment and retain the previous
Worker version for rollback. Console error/retry UI is a separate image update.

Validation: Worker format and TypeScript checks; npm test runs local runtime and
routing tests with coverage. New cases cover US/HK query routing, unauthenticated
requests, write rejection and denied admin paths.
