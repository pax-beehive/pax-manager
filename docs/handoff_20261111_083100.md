# Secretary progress and status scope

## Evidence and boundaries

The production Manager was e6ae940, which already contains the earlier terminal
recovery correction. New Secretary work was completing while an older unknown
attempt and invalid-output tasks remained blocked. The unknown legacy attempt
has no prepared correlation or terminal record. Its idle runtime state does not
prove a completed/canceled execution. Do not fabricate a terminal or blindly
reset its retry budget; use the existing owner task control for an explicit
restart when appropriate. Issue 074 retains this operational boundary.

The progress request is independent of task execution. Its exact production SQL
exceeded the existing eight-second limit, with a one-second lock timeout that
did not fire. It reused the old per-message replacement predicate; issue 077's
search batch optimization did not change this path.

## Changes

Only the default progress SQL builder materializes relevant owner/session
scopes, classifies display arrays once, and expands replacement targets once.
The scope builder remains shared without changing the pending-source query.
Valid nonempty string/null arrays override parent IDs; missing, empty, nonarray
or invalid-member arrays fall back to the parent. Null entries do not match a
message. Matches remain scoped by agent, session and message ID. Display rows
do not acquire extra role/node filtering. Original source ownership, deletion,
archive and internal-session predicates remain authoritative.

Progress still computes current full-visible-text hashes and compares exact
owner/canonicalization versions before aggregating all global counts and
applying its existing session cursor. It does not use a stale count cache or
skip original-source validation. There is no schema, index, generated artifact,
API shape or production deployment change.

Manager's overall status now considers Processing before another conversation's
unknown/ordinary blocked state, while preserving disabled, offline, recovery and
connection retry precedence. Execution diagnostics remain available. The
companion Console change retains those warnings, scopes retry pauses to affected
conversations, names the backlog Unfinished and links to task controls. It also
includes the separately requested summary-to-origin-session action.
