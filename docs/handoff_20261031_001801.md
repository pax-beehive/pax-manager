# Workspace search MVP handoff

## Location and scope

Worktree: `/Users/gengcongkai/pax_workspace/work/search-mvp-manager`
Branch: `codex/search-mvp`, based on `0a96512`.

The original Manager checkout contains unrelated uncommitted notification and
approval-index work; it was not changed. This implementation is uncommitted in
the isolated worktree and has not been deployed to a remote environment.

The MVP provides owner-only title/content substring search, versioned source
reads, immutable summary publication, and a standalone Secretary MCP adapter.
It does not generate summaries, schedule Secretary work, restart its stopped
pipeline, or implement shared ACLs. The companion Console screen is implemented
in `/Users/gengcongkai/pax_workspace/work/search-mvp-console` on branch
`codex/search-mvp-console`; its original dirty checkout was also left untouched.

## Modules and flow

- `domain/search.go`: one canonical visible message across ordered text parts;
  whole-body hash and stable references, independent of part boundaries.
- `storage/search_*`: authoritative owner/visibility reads, bounded context,
  durable coalesced queue, leases, retries and backfill.
- `search/`: Elasticsearch client, literal wildcard escaping, case-insensitive
  substring matching, authenticated owner filters, PIT pagination, external
  versions and redacted persistent tombstones; context-bound worker lifecycle.
- `userapi/workspace_search.go`, `search_receipts.go`: HTTP business operations,
  current PG revalidation before snippets, bounded read views, HMAC receipts and
  evidence checks. The transport handlers only decode/delegate.
- `domain/summary.go`, `storage/summary.go`: immutable summary revisions,
  complete coverage snapshots, exact child-summary refs, optimistic concurrency,
  idempotency and recursive current source authorization.
- `tools/secretary_search_mcp.py`: stdio `search`, `read`, `expand`, and
  `publish_summary` tools over authenticated Manager HTTP APIs.

PG mutation and dirty marking commit together through narrow database triggers.
The worker reads a consistent current projection, indexes one document per
message, and acknowledges only that processed revision. Summary publication
freezes all coverage, not only quoted messages, in the same transaction as the
new revision and exact source links. Only current summaries are indexed; explicit
old revisions and message snapshots remain PG reads with current access checks.

## Schema and generated API

`EnsureSchema` applies `db/init.sql`, `db/summaries.sql`, then `db/search.sql`.
All DDL is repeatable. Three summary tables and one sync-state table are added.
There is no separate session-summary entity. Current summary means the highest
immutable revision of its logical summary ID.

The source of truth is `api/pax_manager.thrift`; API/model/router/OpenAPI outputs
were regenerated with `make generate`. Generated handlers are not used for
business logic. Store interfaces for these features are optional narrow domain
interfaces, so existing generated mocks did not require new giant Store methods.

## Operations and limits

See [search_contract.md](search_contract.md),
[search_deployment.md](search_deployment.md), and
[secretary_search_mcp.md](secretary_search_mcp.md).

Set a persistent shared `SEARCH_READ_RECEIPT_SECRET` of at least 32 bytes in
production. Without it, receipts expire on process restart and callers reread.
ES ports are private in application Compose/VM helpers. The temporary ES test
service publishes only loopback. No remote VM deployment was performed.

Keep queue rows, monotonic versions and tombstones when retaining an ES index.
Rebuilding uses a new index and explicit requeue, never resetting source versions
against an existing index. Short substring queries can scan many candidates;
measure latency against the real corpus before setting an SLO.

Source snapshots are plaintext and remain governed by current source ownership
and deletion/visibility. Existing Manager message IDs are projection identities;
local exports and cross-agent aliases still need ingestion-layer mapping before
they can be admitted as these source IDs. E2EE ciphertext is not indexed.

The worker defaults to batches of 20 once per second, a five-minute lease and
five-second initialization retry. PG snapshots and summary access remain
available when ES is unavailable. Summary generation/processing checkpoints
remain Secretary responsibilities.
