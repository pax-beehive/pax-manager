# Legacy ACP model selection

## Behavior and boundaries

Plaintext sessions whose agents advertise `models.currentModelId/availableModels`
can now switch models through the existing session configuration API. This supports
Hermes without special-casing its name. A standard model option always wins over
the compatibility path; an RPC failure never triggers a fallback.

`internal/manager/session_legacy_model.go` projects the advertised catalog into a
REST `model` select option without inserting a synthetic option into stored ACP
data. `session_config.go` validates the submitted value and claims the existing
session-control connection. Standard selections call `session/set_config_option`;
legacy selections call `session/set_model` with `sessionId` and `modelId`.

Legacy setters return an empty acknowledgement. After success, Manager updates
the selected ID, observation time, and source while retaining the advertised
catalog and other options. Storage updates the session model along with the
configuration metadata. On rejection, no selection is persisted. The existing
Console mutation updates its query cache only on success and surfaces failures.

The Console uses its existing model settings page for this normalized option.
Older Manager snapshots with only `legacy_models` still show a read-only fallback.
Console architecture, operating, and design documentation now describe this flow.

## Contracts and deployment

No REST paths, schema fields, database migrations, or generated artifacts changed.
No generator was needed. Paxd's existing generic session routing carries the ACP
method; paxd and paxl need no changes. Deploy the updated Manager to enable the
compatibility selector. No live service or configuration was changed in this task.

Hermes requires an idle session for model switches. Its busy errors are surfaced
without changing the displayed model. Advertising a legacy catalog does not prove
every agent implements the setter; unsupported-method errors remain visible.
Legacy selection does not provide catalog refresh, reasoning-effort settings,
encrypted configuration, or new legacy agent API routes.
