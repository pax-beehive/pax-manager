# Soniox Streaming Dictation

## Scope

Add Soniox as a per-instance voice provider. The US instance retains OpenAI.
Only HK should select Soniox. Browser endpoints and the wire protocol are
unchanged; no Console changes or generated artifacts are needed.

## Implementation

- `internal/manager/voice/soniox.go` owns provider authentication, configuration,
  binary audio writes, transcript accumulation, stop/drain and error handling.
- `voice.go` registers `soniox` and its settings.
- `internal/manager/config` loads the environment, and `voice_handlers.go`
  maps it to the provider. Existing authenticated admin checks remain unchanged.

Soniox uses 16 kHz mono signed little-endian PCM. Default endpoint:
`wss://stt-rt.soniox.com/transcribe-websocket`; default model: `stt-rt-v6`.
Authentication is a Bearer header, never a URL query or browser credential.
`VOICE_LANGUAGES` becomes language hints (`zh-cn,en` becomes `zh,en`).
Normalized keywords map to `context.terms`; conversation context maps to
`context.text`. Endpoint detection is enabled.

Final tokens are appended exactly once; provisional tokens replace the previous
tail, including an explicit empty token list. Provider token whitespace is
preserved. `<end>` and `<fin>` are control markers and never appear in text.
Trailing finalized Latin subwords stay in the partial tail until their boundary
is known so the existing Console joining rule cannot introduce extra spaces.
Stop sends an empty text frame and waits for `finished`, retaining late finals.
EOF before `finished` is an error. Provider errors keep their code, type and
message while redacting the configured key, including WebSocket close reasons.

## HK configuration

Set only on HK, using the private credential already installed on that host:

```text
VOICE_PROVIDER=soniox
SONIOX_API_KEY=<private credential>
```

Optional: `VOICE_SONIOX_URL`, `VOICE_SONIOX_MODEL`. Leave the safe defaults
`VOICE_ADMIN_ONLY=true` and `VOICE_MAX_SESSION_SECONDS=300` unchanged.
The existing Release executor preserves runtime environment during image updates.
Persistent env changes require recreating the container, not docker restart alone.

Rollback: remove `VOICE_PROVIDER` from HK configuration and recreate its Manager.
Do not modify US provider credentials or configuration.

## Tests and operations

BDD/testify scenarios were written before implementation and first failed on
missing settings/provider symbols. Further red/green regressions cover subword
joining, credential echoes in close frames, and removal of provisional tokens.
Fake WebSocket tests cover authentication/config, normalized bounded hints,
binary PCM, transcript replacement, stop/final drain, provider errors, invalid
configuration, malformed responses, premature EOF and idempotent close/finish.
Config and Manager tests cover mapping, discovery and admin-only behavior.

Use `GOWORK=off` in this worktree because the parent workspace has a go.work.
Verification commands:

```sh
GOWORK=off make fmt-check
GOWORK=off make lint
GOWORK=off GOCACHE=/tmp/pax-manager-go-cache go test -count=1 ./...
GOWORK=off GOCACHE=/tmp/pax-manager-go-cache go test -race -count=1 -coverprofile=/tmp/pax-soniox-voice-coverage.out ./internal/manager/voice
GOWORK=off GOCACHE=/tmp/pax-manager-go-cache go build -o /tmp/pax-manager-soniox-build-check ./cmd/manager
```

The pre-integration HK direct provider probe succeeded twice with synthetic
mixed Chinese/English speech: first text about 1.25 seconds after audio start,
and stop-to-finished about 0.25 seconds. Terms preserved `session-composer` and
`Mic`. This is provider evidence, not browser acceptance or a human-accent test.
